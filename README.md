# Piel-de-pintura-202507039
"Piel de pintura" Video Juego basado en el famoso juego de steam "mecha chamaleon"

# Fase 1 – Análisis

En esta fase se realizó el análisis del videojuego Piel de Pintura. Se
definió la idea principal, el objetivo del juego, los personajes y las
mecánicas principales.

El juego consiste en que los jugadores deben explorar el mapa, recuperar
los colores perdidos y utilizar el camuflaje para evitar al Cazador de
Tinta. El Cazador debe localizar y capturar a los jugadores antes de que
termine el tiempo.

También se identificaron los elementos necesarios para desarrollar el
juego en Python, como funciones, listas, tuplas, variables y manejo de
errores.

# Fase 2 – Diagrama de flujo

En esta fase se diseñó el diagrama de flujo del juego para representar
de forma visual el funcionamiento de la partida.

El diagrama permite organizar las acciones que realizan los jugadores y
el Cazador de Tinta, así como las decisiones que determinan el avance
del juego.

También se establecieron los diferentes caminos que puede tomar la
partida hasta llegar a la finalización y mostrar el resultado.

# Fase 3 – Código

En esta fase se llevó el análisis y el diagrama de flujo a un programa
funcional desarrollado en Python.

Se programaron los jugadores, el Cazador de Tinta, el mapa, los colores,
el movimiento, el camuflaje, la pistola de pintura, los turnos, el tiempo
de partida y las condiciones de victoria y derrota.

El resultado es un juego de consola en Python que permite iniciar
partidas, jugar diferentes turnos y mostrar el resultado final.
